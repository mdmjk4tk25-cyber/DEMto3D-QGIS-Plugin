# DEMto3D

Extension for 3D printing DEMs (Digital Elevation Models) in QGIS.

DEMto3D allows exporting a DEM to STL format.

More information about this project, as well as the download, user manual and installation guide, can be found at http://demto3d.com.

DEMto3D was developed as part of the thesis:
"Development of a 3D printing module of digital elevation models based on a low-cost system"
of the Degree in Geodesy and Cartography Engineering at the University of Jaén.
